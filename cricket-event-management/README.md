# CRICKETARENA

CRICKETARENA is a static frontend website for cricket tournament management. It includes pages for home, about, events, teams, registration, and contact.

## Pages

- `index.html`
- `about.html`
- `events.html`
- `teams.html`
- `register.html`
- `contact.html`

## Folders

- `css/style.css` for custom styling
- `js/main.js` for interactions and form validation
- `bootstrap/css/bootstrap.min.css` for local Bootstrap-compatible CSS classes
- `bootstrap/js/bootstrap.bundle.min.js` for local Bootstrap-compatible navbar behavior

## Run

Open `index.html` in a browser, or serve the folder with any static web server.
